# 批改侦探 GradeDetect

> 计算机专业实验报告智能评阅平台 —— AI 不替老师打分，AI 给老师证据。
>
> 粤港澳大湾区 AI Coding 创新大赛 · 方向一「AI + 教学管理助手」参赛作品

## 一句话定位

面对一门课 120 份实验报告，助教批一周；调库的、贴假截图的、抄学霸的，人眼根本看不过来。批改侦探让 AI 按评分点逐项核查，**每个扣分点附带报告原文证据、点击即定位高亮**，并用三重本地算法检测造假——老师只复核 AI 给出的证据链。

## 三大核心特性

### 1. 证据溯源（灵魂功能）
- AI 按评分细则逐项核查，每项输出：得分 + verdict（全对/部分/未达成）+ **报告原文逐字摘录** + 核查理由
- 点击证据引用块，左侧报告原文自动滚动定位并高亮 2 秒
- 教师复核改分留痕："AI 建议 X 分 → 教师改为 Y 分"，确认定稿后锁定

### 2. 造假检测三件套（本地算法，无需 AI、无需联网）
- **调库检测**：静态扫描 `str.find()` / `re.search()` 等库函数直接调用，抓"用内置函数冒充自实现 KMP"
- **截图输出比对**：推演代码逻辑与截图声称的运行结果是否矛盾（有 bug 的代码不可能"全部通过"）
- **相似度查重**：代码归一化（标识符→VARn、字符串→STRn、去注释）后 3-gram 余弦相似度矩阵 + **最长公共连续文字段**双信号判定——改变量名无效，正常写同一算法的同学不会误伤

### 3. 班级学情看板
- 分数分布直方图、各评分点得分率（最低项标红提示课堂重点）
- 一键生成讲评提纲：典型错误代码对比 + 讲解要点 + 课堂提问建议 + 学术诚信通报
- 成绩单导出 CSV（AI 建议分 / 教师定稿分双列）

另外支持 **AI 生成评分细则**：粘贴实验指导书，自动抽取结构化评分点——覆盖方向一"多模态教学素材解析"子题。

## 架构与技术栈

**纯前端 SPA，零后端、零数据库，构建产物可静态部署。**

```
React 18 + TypeScript + Vite + Tailwind CSS 4
├── 批改台     任务卡片 / 评分细则 / 一键批改（进度条）
├── 批改详情   报告原文 ↔ 评分卡片双栏 / 证据定位高亮 / 教师复核留痕 / 定稿
├── 真实性体检 检测矩阵 / 相似度热力图 / 归一化代码预览
├── 班级看板   统计卡 / SVG 直方图 / 得分率条形图 / 讲评提纲 / CSV 导出
└── 设置       BYOK 配置 / 测试连接 / 数据重置
```

**AI 双轨设计**：
- **在线模式**：用户在设置页填入 OpenAI 兼容接口（Base URL / API Key / 模型名），支持 DeepSeek、通义、智谱等任意兼容网关；AI 输出强制 JSON 契约（评分项/证据/评语），解析失败自动重试一次
- **演示模式**：未配置 Key 时自动进入，全部 AI 功能返回与剧本严格自洽的预置数据（含 6 份报告、批改结果、检测判定、讲评提纲），评委打开链接即可完整体验，控制台零报错

**数据**：localStorage 持久化（key 前缀 `gd_`），刷新不丢，支持一键重置演示数据。

- 构建命令：`npm run build`
- 输出目录：`dist`
- 无需任何环境变量（API Key 由用户在应用内填写）
